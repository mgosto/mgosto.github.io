# World Clock

An interactive world clock application that displays the current time across multiple cities around the globe.

## Features

- **24 City Displays** — Shows current time and date for 24 major cities across different time zones
- **Hide Cities** — Toggle city visibility to customize your view
- **Reorder Cities** — Drag and drop to arrange cities in your preferred order
- **Dark Theme** — Modern, visually polished dark interface with smooth animations
- **Responsive Design** — Works seamlessly across different screen sizes

## Purpose

This application provides a quick, elegant way to check the time across different regions without switching between multiple tools or websites. Perfect for coordinating with global teams or keeping track of time zones you regularly interact with.
